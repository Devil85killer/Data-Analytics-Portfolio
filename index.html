Banking Audit & Fraud Detection System

📂 Domain: Banking & Finance
📊 Dataset: 500K+ Rows
⏱️ Duration: 3 Weeks
🛠️ Tools: Advanced SQL, Power BI

Problem: The compliance team was manually auditing thousands of transaction logs, creating a reactive and slow environment vulnerable to rapid fraudulent transfers.

Approach: Engineered advanced SQL scripts utilizing Window Functions (LEAD, RANK, OVER) and CTEs to automatically flag "Rapid High-Value Transfers" occurring outside normal banking hours.

Business Impact: Identified anomaly patterns that could reduce manual compliance audit time by an estimated 60% and proactively flag high-risk transfers for 2FA verification.

FinSight: Predictive Credit Risk Engine

📂 Domain: Credit Risk
📊 Dataset: 10,000+ Rows
⏱️ Duration: 4 Weeks
🛠️ Tools: Python (ML, SMOTE), DAX, Power BI

Problem: Outdated, static risk assessment rules were failing to identify high-risk customers prior to default.

Approach: Built a predictive pipeline using Python. Applied SMOTE to balance data, trained a Random Forest Classifier to extract default probabilities, and deployed insights into a dynamic Power BI dashboard using complex DAX calculations.

Business Impact: Increased model recall for minority high-risk profiles by 100%, establishing a framework for proactive credit limit adjustments based on behavioral scoring.

Olist E-Commerce Logistics Churn

📂 Domain: E-Commerce
📊 Dataset: 100K+ Rows (5 Tables)
⏱️ Duration: 2 Weeks
